# 🛠️ Technology Stack

This document outlines the core technologies used in the NeuroCare AI application, organized by domain. The technologies listed here are formatted with their proper industry names for use in presentations.

## Frontend & Core Framework
* **React Native**: Core framework for building the cross-platform native mobile application.
* **Expo**: Development platform and toolchain accelerating React Native development.
* **React**: The underlying library for building user interfaces.
* **React Native Web**: Enables running the React Native application seamlessly on standard web browsers.

## State Management & Navigation
* **Zustand**: A lightweight, fast, and scalable global state management solution.
* **React Navigation**: The industry standard for routing and screen transitions in React Native apps.

## UI, Design & Assets
* **Lucide**: A consistent, clean, and modern icon library.
* **React Native SVG**: Engine for rendering crisp, scalable vector graphics across devices.
* **Expo Linear Gradient**: Provides dynamic background styling, modern gradients, and rich aesthetics.

## Data Storage & Offline Capabilities
* **Async Storage**: Persistent local key-value storage engine enabling offline-first capabilities on mobile devices.
* **IndexedDB**: Persistent local storage for the web environment.

## Artificial Intelligence & Voice Processing
* **Groq Cloud AI**: Ultra-fast AI inference engine powering the conversational companion.
* **Whisper AI (via Groq)**: High-accuracy, multilingual speech-to-text transcription engine.
* **React Native Voice**: Native module handling real-time local speech recognition.
* **Expo Speech**: Provides Text-to-Speech (TTS) capabilities for auditory feedback and conversational responses.
