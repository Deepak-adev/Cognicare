# sih

Problem Statement:
The North Eastern Region (NER) is experiencing a growing need for accessible and effective support for elderly individuals affected by age-related cognitive disorders such as dementia and memory loss. Families in remote and rural areas often face significant challenges in accessing specialized neurological care, cognitive therapy, and long-term elderly support due to limited healthcare infrastructure and geographical barriers.

Dementia can lead to progressive memory decline, confusion, anxiety, reduced attention, and social isolation. At the same time, caregivers often struggle with continuous monitoring, cognitive engagement, medication and routine management, and identifying changes in a patient's condition. Existing digital solutions are predominantly generic and lack personalization, regional-language support, cultural relevance, offline accessibility, family involvement, and intelligent long-term monitoring.

Therefore, there is a need for an AI-powered, accessible, engaging, and culturally inclusive cognitive care platform specifically designed for elderly dementia patients in the NER. The platform should provide adaptive cognitive activities and memory assistance while supporting daily routines, voice-based interaction, caregiver monitoring, personalized experiences, and offline functionality for low-connectivity environments.

Proposed Solution:
Module 1:
The user interacts with the AI through a voice-based conversation instead of filling out a lengthy registration form. The AI collects information such as name, age, language, location, caregiver, medical details, daily routine, medications, interests, and known cognitive difficulties.

The AI analyzes the conversation and automatically creates a personalized user profile dashboard. As the user continues using the platform, their game performance, response time, memory, attention, and other cognitive indicators are continuously analyzed.

Based on these insights, the AI automatically updates the user's profile, adjusts difficulty levels, recommends personalized cognitive activities, and tracks progress over time.
